# Micronova（Tarkov复刻MOD）详细开发路线图

本路线图基于 Escape from Tarkov 的核心玩法，结合 Minecraft 1.20.1 + Fabric 的开发方式，目标是实现一个真实、硬核、完整的生存射击MOD。所有功能需为可用代码，避免伪实现和半成品。

## 1. 基础架构与环境搭建
- [ ] Fabric MOD 基础工程与多端分层（main/client/shared/test）
- [ ] 数据驱动架构（JSON配置武器、弹药、护甲等）
- [ ] 网络通信与同步（自定义数据包、状态同步）
- [ ] 单元测试与CI集成

## 2. 角色与健康系统
- [ ] 细分身体部位（头、胸、腹、手、脚等）与独立健康值
- [ ] 出血、骨折、瘫痪、疼痛等状态
- [ ] 医疗物品与治疗机制
- [ ] 生命体征与死亡判定

## 3. 武器与弹药系统
- [ ] 武器种类（手枪、步枪、霰弹枪等）与配件系统
- [ ] 弹药类型、穿甲/伤害/后坐力/散布等参数
- [ ] 武器耐久、卡壳、损坏机制
- [ ] 武器组装与拆解

## 4. 护甲与防护系统
- [ ] 护甲部位覆盖与耐久
- [ ] 穿甲判定与损坏
- [ ] 头盔、面罩等特殊装备

## 5. 战斗与弹道系统
- [ ] 真实弹道（初速、重力、穿透、反弹）
- [ ] 命中判定与伤害计算
- [ ] 近战与投掷物

## 6. 物品与背包系统
- [ ] 物品栏/背包/保险箱/容器
- [ ] 拖拽、堆叠、丢弃、拾取
- [ ] 物品耐久与损坏

## 7. 经济与交易系统
- [ ] 任务/商人/市场
- [ ] 货币、物品交换
- [ ] 保险与回收

## 8. AI与敌对单位
- [ ] PMC/Scav/AI敌人
- [ ] 行为树/巡逻/战斗/撤退
- [ ] 语音与互动

## 9. 地图与副本系统
- [ ] 多张地图/副本/出生点/撤离点
- [ ] 关卡环境交互（门、箱子、陷阱）
- [ ] 时间、天气、照明

## 10. UI与交互
- [ ] HUD（健康、弹药、状态）
- [ ] 交互菜单、背包界面
- [ ] 任务/提示/日志

## 11. 多人联机与同步
- [ ] 玩家状态同步
- [ ] 战斗与物品交互同步
- [ ] 断线重连与异常处理

## 12. 特色与创新（可选）
- [ ] 角色成长/技能系统
- [ ] 语音通信/无线电
- [ ] MOD可扩展性与API

---

> 每一阶段均需配套单元测试与CI通过，所有功能需为可用代码。可根据优先级灵活调整开发顺序。

如需优先实现某一子系统，请指定。
